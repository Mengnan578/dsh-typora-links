# Changelog

## 0.1.1 — 2026-11-09

- First public release.
- Plain click on a local Markdown link in the DSH conversation opens it in
  Typora; ⌘/Ctrl/Shift/Alt-click keeps the in-app preview.
- Automatic fallback to the preview when the file is missing, the Host refuses
  the path, or Typora cannot be resolved.
- Optional bundle config: `appName`, `bundleId`, `extensions`,
  `gestureWindowMs`, `requireExplicitApp`.
